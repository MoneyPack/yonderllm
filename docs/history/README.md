# Historical planning records

The files under this directory are planning artefacts from the September 2026
hardening round (`improve/hardening-ecosystem`, merged as PR #1). They are kept
because they record why several decisions were made; they are **not** current
documentation and are not maintained.

- [`specs/2026-09-16-yonderllm-hardening-and-ecosystem-design.md`](specs/2026-09-16-yonderllm-hardening-and-ecosystem-design.md)
  — the design brief for the ten approved improvement areas.
- [`plans/2026-09-16-yonderllm-hardening-and-ecosystem-plan.md`](plans/2026-09-16-yonderllm-hardening-and-ecosystem-plan.md)
  — the task-by-task implementation plan derived from that brief.
- [`plans/2026-09-16-execution-results.md`](plans/2026-09-16-execution-results.md)
  — what was actually delivered against the plan.

Where a record here disagrees with the code or with the maintained guides, the
code and the guides win. Current behaviour is described in [SPEC.md](../../SPEC.md),
the [README](../../README.md), and the `docs/` guides linked from it. The
security posture these plans aimed for is tracked in the
[threat model](../THREAT_MODEL.md).
