# Community conduct

Be respectful, constructive, and welcoming. Critique code and ideas, not people.
Harassment, threats, discriminatory abuse, and disclosure of another person's
private information are not acceptable in issues, pull requests, or discussions.

Maintainers may edit or remove abusive content, restrict participation, or close
threads to protect contributors. Report problems to repository maintainers using
an available private contact on their GitHub profiles; avoid reposting private
information in public reports. This policy does not promise a response time.
